## Required Parts
> Many of these parts with be in a bag labeled Extruder Kit
{.is-info}

- Bearing, MF148ZZ
- Machine Screw, BHCS, M3x25
- M3x3 Set Screw
- Spider Shaft
- Primary Gear
- Bushing, POM, 8x4x11
- Idler Gear, Orbiter 2
- Shaft, 4x16
- Thumbscrew, M3x30
- Spring, 1x5.9x11.3mm
- Bearing, MR148ZZ
- ECAS04 Bowden Coupler
- Shim Washer, 3x6x0.5mm
- Heatset Insert, Brass, M3x6x5
- 3x Heatset Insert, Brass, M2.5x3x4
- 4x Machine Screw, BHCS, M2.5x18
- 2x Self-tapping Screw, M2x10
- Z Endstop and Cable
